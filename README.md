# Web Primitives & Reactive TypeScript Kit 🛠️

A modern, type-safe suite of essential frontend engineering utilities, reactive state signals, and asynchronous throttling mechanics.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0+-blue.svg)](https://www.typescriptlang.org/)

## 📦 Features
- **Async & Timers**: `debounce`, `throttle`, exponential backoff retry.
- **Deep Merge**: Zero-dependency recursive immutable object merging.
- **Reactive Signals**: Granular subscription-based reactive stores without heavy frameworks.

## 🚀 Quickstart
```typescript
import { Signal, debounce } from "web-primitives-kit";

const count = new Signal(0);
count.subscribe((val) => console.log(`Count updated: ${val}`));
count.set(1);
```
