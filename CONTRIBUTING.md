# Contributing Guidelines

Thank you for your interest in contributing to this project!

## 🌿 Branch Naming Conventions
- `feature/<description>` for new capabilities
- `fix/<description>` for bug and edge-case fixes
- `perf/<description>` for performance enhancements
- `docs/<description>` for documentation updates

## 📝 Commit Standards
We strictly follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` A new feature
- `fix:` A bug fix
- `test:` Adding or updating tests
- `refactor:` Code change that neither fixes a bug nor adds a feature
- `perf:` Code change that improves performance
- `docs:` Documentation only changes
- `chore:` Maintenance tasks and dependencies

## 🧪 Testing Before PR
Ensure all tests and linters pass before opening a pull request.
